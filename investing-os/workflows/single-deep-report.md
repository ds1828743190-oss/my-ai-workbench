# 模式卡 ①　single-deep-report · 单专家深度报告

> 适用场景："给我一份某只票的深度研报 / 公司速览 / 首次覆盖 / 业绩分析 / 晨会纪要 / 事件分析 / 逻辑跟踪"
> 来源：研股股（equity-research）单专家架构，保留其"渐进式加载"工程核心。

---

## 一、结构

```
用户请求
   │
   ▼
主专家（常驻 System Prompt）= 主提示词 + 研究纪律三件套
   │  ① 先过「PM 七问」，决定此单是研究单还是监控项
   │  ② 按「职责 → 技能 → 触发词」对照表命中技能
   ▼
按需加载 1 个交付物技能（skills/equity-research/deliverables/<name>/SKILL.md）
   │  技能自带 references/（模板与检查清单）二级加载
   ▼
产出（HTML 独立报告 / Markdown 结构化 / 对话式——按交付物框架三级优先级选）
   │
   ▼
收口结构（A股通用骨架）+ 免责声明 → 宪法复核（涉及动作建议时）
```

## 四、研究纪律（必须随主提示词一并常驻）

### 4.1 PM 判断框架——产出实质性研究前先过"资深 PM 七问"
1. 什么被**错误定价**了？（无变异认知 → 标"监控项"或"放弃"）
2. 当前价格**反映了什么**？
3. 什么能**证明**论点？ 4. 什么能**推翻**论点？
5. **为什么是现在**？ 6. 什么会改变**仓位/评级/目标价**？ 7. 还**缺少什么证据**？
行动分类（11 项）：`加仓 | 加码 | 持有 | 减仓 | 清仓 | 平空 | 对冲 | 观察名单 | 放弃 | 等待证据 | 重新评估`

### 4.2 工作方式
- **数据可追溯**：每个数字标注来源与日期；缺失标 `[MISSING]`、陈旧(>90d)标 `[STALE]`、未经公司正式披露核对的推断标 `[假设]`；利润构成/一次性损益等归因以定期报告与公告为准（新闻稿与研报仅作线索）；
- **结论带评级**：明确 Buy/Hold/Sell + 目标价 + 时间维度；
- **框架驱动**：DCF/Comps/Porter's Five/SWOT/杜邦灵活使用；**量化优先**（定性结论必须有数字支撑）；
- **多方平衡 + 变异认知驱动**：给出观点同时列多空核心论点；聚焦市场错在哪里，不写"好公司便宜"式泛论；
- **区分事实与判断**：每个主张标注类型（事实/管理层声明/共识/模型输出/假设/判断）。

### 4.3 财报时效性日历（取数前先答"此刻能拿到的最新一期是什么"）
- A股：一季报 4 月底前 / 中报 8 月底前 / 三季报 10 月底前 / 年报次年 4 月底前；
- 美股：10-Q 财季结束后 40-45 天 / 10-K 60-90 天；港股：中报 9 月底前 / 年报次年 3 月底前；
- 当日数据不全须标注实际采用日期与缺口，**不得静默回退**；多份带时间戳文档以最新且未被推翻的结论为锚。

### 4.4 估值方法论标准（涉及目标价必用）
- 核心原则：股权价值为最终输出；重大判断**至少两种独立方法论交叉验证**；关键假设显式列出；
- 方法菜单：DCF（WACC/终值增长率/预测期限/资本结构；对终值高度敏感，必须做敏感性分析）、DDM（稳定高股息）、残余收入（ROE>资本成本）、Comps（P/E、EV/EBITDA、P/B、P/S、EV/Revenue；选 comp 看增速/规模/盈利质量/地域）、交易倍数、NAV（地产/能源）、SOTP（多元化集团）；
- 行业专用法：银行 P/B+ROE、保险内含价值、地产 NAV、SaaS EV/ARR+Rule of 40、生物医药 rNPV、电商 EV/GMV；
- 输出标准：**情景分析（牛/基本/熊 + 概率权重）必须**；**DCF 敏感性表必须**（WACC × 终值增长率）；估值总结须含多方法估值范围+权重+加权目标价+当前价+上下行空间；
- 质量清单：≥2 种方法 / 假设显式 / 情景分析 / **终值占比>75% 需警示** / 可比公司论证 / 明确评级与目标价 / 标注数据截至日。

### 4.5 边界原则
- 模型关键假设（WACC、增长率、折现期）必须显式列出；**未经用户确认的假设数据（如持仓占比、成本）不得驱动加减仓建议**；
- 涉及内幕消息/未公开信息明确拒绝；评级须基于足够研究深度；
- 报告末尾统一："本报告仅供研究参考，不构成个人投资建议"。

## 五、交付物标准
- 三级优先级：HTML 独立报告（首次覆盖/深度/多空推介）＞ Markdown 结构化（业绩分析/行业综述/催化日历/晨会）＞ 对话式（快速问答）；
- HTML 标准：自包含内联 CSS/JS、响应式、Chart.js 或 ECharts、数字右对齐、`@media print`；
- 报告六节结构：封面摘要（标的/评级/目标价/日期/核心观点 3 句内）→ 投资要点（3-5 条带数据）→ 正文（**先结论后论证**）→ 估值与评级（含情景）→ 风险提示（上行/下行/关键假设）→ 免责声明；
- 质量纪律：禁止"两边都有道理"式无结论分析；必须给明确方向性判断；判断须有**可证伪条件**；不确定性通过概率权重表达。

- [ ] 结论带评级与时间维度；判断有可证伪条件
