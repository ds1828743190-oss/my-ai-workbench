# 模式卡 ②　roundtable-parallel · 星型圆桌并行

> 适用场景："多视角看看这只票 / 近大盘怎么看 / 我这几只持仓怎么样"——**分歧本身就是产出**
> 来源：投研专家团（stock-partner-team）圆桌架构 + stock-partner-lead 主理人工程纪律（全文蒸馏）

---

## 一、结构（hub-and-spoke 星型）

```
                    ┌──────────────────────────────┐
                    │ 主理人 圆汇众（编排者）         │
                    │ experts/leads/stock-partner-lead.md │
                    │ 拆维度 → 并行调度 → 汇编收口    │
                    └──────────────┬───────────────┘
        ┌──────────┬──────────┬────┴─────┬──────────┬──────────┐
        ▼          ▼          ▼          ▼          ▼          ▼
    产业策略师   信号派首席   估值分析师  逆向投资人  财报研究员  短线冲浪手
    (experts/roundtable/ 下 6 份人格，各自取数 → 各自方法论 → 回传)
        │          │          │          │          │          │
        └──────────┴──────────┴────┬─────┴──────────┴──────────┘
                                   ▼
                    主理人汇编：圆桌报告（4 模块）→ HTML 渲染
```

## 二、角色配置（6 席 + 主理人）

| 席位 | 文件 | 研究维度 |
|---|---|---|
| 🌊 产业策略师 | `../experts/roundtable/industry-strategist.md` | 产业趋势、产业链拆解、景气度排序、牛熊判断 |
| 📡 信号派首席 | `../experts/roundtable/signal-chief.md` | 四层信号对齐、系统性风险、信号衰减、操作纪律 |
| 🧮 估值分析师 | `../experts/roundtable/valuation-analyst.md` | PE Bands/PEG 精确定价、大类配置、核心+卫星 |
| 🏔️ 逆向投资人 | `../experts/roundtable/contrarian-investor.md` | 支撑位分批、情绪极值、深套安抚、极简框架 |
| 🔬 财报研究员 | `../experts/roundtable/fundamental-researcher.md` | 财报深挖、季度跟踪、生活体感、管理层动作 |
| ⚡ 短线冲浪手 | `../experts/roundtable/shortterm-surfer.md` | 当周主线、集合竞价、龙头识别、技术止损 |

维度允许重叠（估值×逆向都看价格、信号×短线都看资金），但**每位成员只用自己的方法论展开，不替他人发声**（易混淆区分见 `../experts/README.md` §四）。

## 三、编排四步

1. **拆解研究维度**：把问题分解为本次需要覆盖的维度，判断每个维度由谁的方法论负责最合适；
2. **维度映射成员**：三个样例——单股深度（财报+估值+信号+产业+逆向+短线全上）、非个股主题（产业+信号+估值+短线，如"新能源还能追吗"）、组合诊断（估值+产业+信号+财报+逆向，每人只出一份**组合视角**报告横跨全部标的）；
3. **并行调度**：同一条消息内并行 spawn 全部成员；调度前主理人**最多取 1 次共享快照**写入任务说明；派单模板见 `README.md` §3.4；
4. **主理人整合**：成员回传的**完整正文**是唯一权威来源（默认不落盘；禁止用 Read 去找成员文件），跨维度取舍由主理人完成。

## 四、汇编产出：圆桌报告 4 模块（章节顺序固定）

### 模块 1 · 结论卡
- **YOU ASKED**：原样引用用户问题；
- **当前关键数据快照**：4-8 个最相关数字，带涨跌方向（涨红跌绿）；
- **圆桌综合视角**：1-2 句完整陈述句，50 字左右写清整体态度 + 共识；
- **核心分析观点（3-5 条）**：每条 = 视角标签（来自上场专家方法论）+ 核心数据/论据 + 该视角的独立判断；
- **圆桌立场分布**：投票数字 + 维度（例：看多 3 / 观望 2 / 看空 1；或问主线时按板块计票）。

### 模块 2 · 子专家观点
本次上场专家**每位一张卡**：头像 + 头衔 → 方法论一句话定调 → 关键数据/证据（含表格/列表）→ 独立结论。**保留关键产物表**（产业链卡位/PEG 分档/四层信号矩阵/龙头止损位/支撑位分批/财报跟踪），模块 2 之外**转述而非粘贴**（可引用标志性句子 `> "..."`）。

### 模块 3 · 深度思考（主持人替你想到的）
- **3a 主持人札记（3-5 条）**：元观察 / 跨成员的隐含模式 / 容易被忽略的暗信号，用主理人**第一人称**写；
- **3b 主持人 Q&A（3-5 条）**：每条带类型标签——🔑 关键（影响结论的转折点）/ ⚠️ 易混淆（同一数据不同解读）/ 🔍 易疏忽（被带过但重要的）/ ⭐ 重要（用户没问但应该问的元问题）。
- **分歧处理**：方向性分歧升华到这里作为"读者应该问的问题"组织，**不单独切"争议焦点"小节**。

### 模块 4 · 后续关注（什么变了应该重新评估）
- **4a 关键变量观察台**：两列表「变量（含当前值）| 重新评估触发线」，每行只写"**阈值 → 该阈值意味着什么（事实判断）**"，例："跌破 5 日线 → 短线强度走弱；跌破 120 日线 → 机构生命线告破，认真审视";
- **4b 综合视角失效条件（3-5 条）**：跨维度铺（基本面/估值/信号/盘面/宏观），每条带**可证伪的具体阈值**，聚焦"什么会让我们错"。

### 硬性要求
长度底线：圆桌报告字数 **≥ 上场成员报告总字数的 70%**；模块 2 把支持与反对的论据都铺出来，让读者有重新评估模块 1 结论的入口。

## 五、三层交付物

| 层 | 内容 | 说明 |
|---|---|---|
| Chat 简版 | 综合视角 1-3 句 → 核心观点 3-5 条按视角分组 → 关键数据 3-4 个 → 态度分布 → 争议焦点 → 免责声明 | 预览层，不在低密度渠道塞高密度内容 |
| 圆桌 MD | 4 模块完整论述 + 全部量化表格 | **信息权威层**，HTML 与 chat 都从它派生 |
| 圆桌 HTML | 调 `../skills/md-to-html/` 渲染（body 片段 → render.py 套壳、自动嵌头像） | 呈现层，**必须交付**，可独立分发 |

## 六、工程纪律（摘要，全文见 `README.md` §三）

- **共享快照**：主理人最多取 1 次；成员禁止重复取同一标的；
- **执行预算**：取数 ≤4 次 / 日K limit≤250 / WebSearch ≤1 次（仅非结构化）/ 报告 800–1500 字 / 写完即回传；
- **恢复纪律**：中断只发一条固定恢复指令，最多恢复 1 次，失败标注「缺席」**禁止代写**；有效回传 ≥4 席即可汇编；
- **等待纪律**：spawn 后静默等待（"已拉起 N 位、在等回传"说一次即可），禁止每收到一位就长篇复述，禁止边等边取数；
- **数据纪律**：结构化数字必须来自数据层；连接器/数据通道不可用时**主动、单独**告知用户降级（不得一句带过），产出中标注「待核实」，交付简述末尾再次提醒；
- **合规**：**禁止指令性结论**（不许"建议买入/加仓/X 成仓"），只用偏多/偏空/观望/分歧或按持仓状态分组的差异化参考；成员不是真人账户（不说"我昨天买了"，说"按我的框架，我会在 XX 价位做 XX"）；历史归历史、实时归实时；每条数据标来源；文末统一免责声明。

## 七、文件位置与收尾
- 仅当用户要求保存时：`{工作空间}/deliverables/stock-partner/<YYYY-MM-DD>/`，命名 `<主题>-圆桌报告.md` + `<主题>-<头衔>.md`（头衔固定 6 个中文词）+ `<主题>-圆桌报告.html`；不允许写 /tmp；
- 交付简述（免责声明之前必出）：一句交付确认 + 产物清单 + 圆桌共识 1-3 句 + （降级时）连接器提醒。

## 八、最小可行实现
- 6 次**并发** LLM 调用：同一"用户问题 + 共享快照 + 日期"，各自人格 md 作 System Prompt → 收集 6 份；
- 第 7 次调用：主理人提示词的"汇编章节"（本卡 §四 模板）合成圆桌报告；
- 第 8 步：写 body 片段 → `python3 skills/md-to-html/scripts/render.py` 出 HTML。丢掉平台团队机制也能拿到约 80% 的多视角价值。

## 九、验收清单

- [ ] 4 模块完整；综合视角 ≤50 字；立场分布有数字
- [ ] 观察台每行"阈值→事实判断"；失效条件可证伪
- [ ] 无指令性结论；成员口吻用第一人称
