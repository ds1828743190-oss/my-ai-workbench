# 模块 02 · 股票研究

> 触发情景：用户问"某股票、行业、财报、估值"。
> 模块目标：产出"经得起 3 年后回看"的研究结论——结论明确、依据可溯、可证伪。
> 配套资产：`../skills/equity-research/`（股票研究工作流：16 类交付物技能 + PM 七问 + 估值标准；交易决策走 `../skills/trading-analysis/`）。

---

## 1. 研究前先过"七问"（拿不出答案 → 标"监控项"或"放弃"）

1. 什么被**错误定价**了？（没有变异认知就不值得写）
2. 当前价格**反映了什么**？
3. 什么能**证明**论点？ 4. 什么能**推翻**论点？
5. **为什么是现在**？ 6. 什么会改变**仓位/评级/目标价**？ 7. 还**缺少什么证据**？

## 2. 五维分析清单

| 维度 | 检查项 |
|---|---|
| 基本面 | 业务构成、收入与利润趋势、ROE/毛利率/净现比、现金流质量（经营现金流 vs 净利润）、资本开支与折旧 |
| 估值 | PE(TTM)/动态 PE、PB、EV/EBITDA 分位；**至少两种方法交叉**（见 §4）；情景分析（牛/基本/熊）必须 |
| 行业与格局 | 景气度、供需缺口、竞争格局（集中度/壁垒/替代）、产业链位置（上中下游哪一环受益） |
| 催化与事件 | 财报预期差、政策、订单、新品、股东行动；催化剂日历（近 1–2 个季度） |
| 技术面/资金面 | 均线体系（5/20/60/120 日）、量价关系、北向/机构/主力资金、拥挤度 |

**财报时效纪律**（取数前先答"此刻能拿到的最新一期是什么"）：
A 股（一季报 4 月底前 / 中报 8 月底前 / 三季报 10 月底前 / 年报次年 4 月底前）、美股（10-Q 40–45 天 / 10-K 60–90 天）、港股（中报 9 月底前 / 年报次年 3 月底前）；当日数据不全须标注实际采用日期，不得静默回退。

## 3. 数据标注规范（贯穿全部产出）

- 每个数字标注**来源 + 日期**；
- 缺失标 `[缺失]` 不编造；陈旧（>90 天）标 `[陈旧]`；未经公司正式披露核对的推断标 `[假设]`；
- 每个主张标注类型：**事实 / 管理层声明 / 共识 / 模型输出 / 假设 / 判断**。

## 4. 估值工具箱（涉及目标价时至少两种方法）

- DCF（关键假设 WACC + 终值增长率 + 预测期限显式列出；终值占比 >75% 需警示；必须附敏感性表）；
- DDM（稳定高派息）；残余收入（ROE>资本成本）；Comps（P/E、EV/EBITDA、P/B、P/S，选可比需论证增速/规模/盈利质量/地域可比性）；
- 行业专用：银行 P/B+ROE / 保险内含价值 / 地产 NAV / SaaS EV/ARR+Rule of 40 / 医药 rNPV / 电商 EV/GMV；
- 产出格式：多方法估值范围 + 权重 → 加权目标价 → 当前价与上下行空间（标注数据截至日）。

## 5. 输出结构（按复杂度裁剪）

```
一句话结论（方向 + 关键理由）→ 核心数据卡（5-8 项带来源日期）
→ 论证正文（先结论后论证；支撑与反对论据都列）
→ 估值与情景 → 风险与证伪条件（可验证的具体指标）
→ 跟踪清单（下次看什么、什么数值触发什么动作）→ 免责声明
```

## 6. 风险点与证伪条件（必写）

- 每条多头逻辑配一条"如果看到 X 数据，逻辑就减弱/破产"——例如增速环比转负、毛利率连续两季下行、核心客户流失、政策反转；
- 拒绝"两边都有道理"式含糊结论；方向判断必须可证伪；
- 信息不足时不硬给评级，说明缺什么证据（转入"观察名单"）。

## 7. 与工具的衔接
- 快速交付：速览卡（公司一页纸）；常态跟踪：财报季用"财报分析"、事件窗口用"事件情景分析"；
- 深度：首次覆盖（含任务模板与质量清单）；估值建模：DCF / Comps；
- 跟踪管理：逻辑跟踪表（论点-证据-状态三列，每季更新）。
