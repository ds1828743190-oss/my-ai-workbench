# 模块 07 · 宏观与市场

> 触发情景：用户问"现在市场怎么样、该积极还是防守、宏观影响"。
> 模块目标：把宏观从"新闻复述"变成"对仓位与结构的可操作判断"。

---

## 1. 核心变量清单（跟踪表）

| 类别 | 关键指标 | 看什么 |
|---|---|---|
| 利率 | 政策利率（MLF/LPR）、10Y 国债收益率、美债 10Y | 方向与斜率（比绝对值重要）；利差（中美利差）与汇率联动 |
| 通胀 | CPI、PPI、核心 CPI | PPI-CPI 剪刀差对企业利润的含义 |
| 流动性 | M2、社融、超额存款准备金、北向/南向资金 | 社融领先实体与市场；资金面决定风格 |
| 政策 | 货币政策措辞、财政力度、产业政策 | 政策拐点常先于基本面拐点 |
| 汇率 | 人民币中间价、美元指数 | 汇率压力→外资与出口链的传导 |
| 外部 | 美联储路径、地缘事件 | 外部冲击→风险偏好→估值中枢 |

## 2. 周期定位框架（四象限：增长 × 通胀）

```
增长 ↑ 通胀 ↑：过热期 → 商品/顺周期占优，警惕政策收紧
增长 ↑ 通胀 ↓：复苏期 → 权益最舒服的窗口
增长 ↓ 通胀 ↑：滞胀期 → 现金/黄金/短债，权益防御
增长 ↓ 通胀 ↓：衰退期 → 债券占优，为下一轮布局
```
定位方法：用 2–3 个客观指标组合判断（如 PMI 方向 + 社融方向 + CPI 方向），**结论标注为"阶段性判断"并写明证伪条件**。

## 3. 市场温度计（可量化的四把尺）

1. **估值分位**：主要指数 PE/PB 的 5 年/10 年分位（数据层可查：中证官方 PE 等）；
2. **股债性价比**：股债利差（E/P − 10Y 国债）——本项目工作台的固化信号即此法（>6% 定投 / 4–6% 观望 / <4% 减仓）；
3. **巴菲特指标**：全A总市值/GDP（<80% 低估 / 80–100% 中性 / >100% 偏贵，仅作交叉验证）；
4. **情绪与资金**：成交额趋势、涨跌家数、两融余额、北向流向、拥挤度（热门赛道的基金重仓集中度）。

> 温度计用法：多个尺子**同向**时才提高置信度；互相矛盾时降低动作幅度而非二选一。

## 4. 风格与结构判断

- 大小盘：流动性与盈利相对变化驱动；大盘价值 vs 小盘成长的轮动跟随流动性周期；
- 价值/成长：利率环境是核心变量（利率上行通常压制长久期成长估值）；
- 防御/进攻：由周期象限 + 市场温度联合决定；
- 输出纪律：给出"当前更适合的 1–2 个风格方向 + 依据 + 证伪条件"，不铺陈全市场。

## 5. 传导链分析（宏观 → 行业 → 组合的可操作落点）

每条宏观判断必须落到传导链才有价值：
```
宏观变量（如降息）→ 直接受益（券商/高股息/债性资产）
→ 二阶受益（地产链/消费）→ 时滞（1–2 个季度）→ 验证指标（成交/信贷/开工数据）
```

## 6. 输出模板裁剪版

```
【情景判断】市场温度（冷/温/热）+ 周期象限（阶段判断，标注依据）
【核心数据】4–6 个温度计读数（每个标来源与日期）
【含义与动作】对仓位的含义（加/持/减的量级区间）+ 对结构的含义（风格/行业倾向）
【证伪条件】什么数据变化会推翻本判断（列出 2–3 条具体指标与阈值）
【注意】宏观判断只调节仓位与结构，不替代个股/ETF 层面纪律
```
