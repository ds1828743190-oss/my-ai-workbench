# 模块 04 · 资产配置

> 触发情景：用户问"整体怎么配、仓位多少、目标收益风险、长期规划"。
> 模块目标：先定"骨架"（大类比例与再平衡规则），再谈"血肉"（具体标的）。

---

## 1. 先补全五类约束（缺一项就影响方案成立性）

| 约束 | 要问清的问题 |
|---|---|
| 目标 | 保值 / 稳健增值 / 积极增值？年化目标区间（用区间不用单点） |
| 风险承受 | 能接受的最大回撤（用"账户浮亏 X% 时睡得着吗"校准，而非问卷分数） |
| 期限 | 资金多久不用（<1 年 / 1–3 年 / 3–5 年 / >5 年）——直接决定权益上限 |
| 流动性 | 是否有随时要用的部分（应急金必须单列，建议 3–6 个月支出） |
| 约束条件 | 是否用杠杆（默认否）、账户类型、税务敏感度、跨境限制、禁投清单 |

## 2. 配置方法（从简到繁，先简后繁）

1. **固定比例（基线）**：如股/债 60/40、50/50；简单、可执行、容易坚持——先证明有比它更好的，再上复杂方法；
2. **风险平价**：按风险贡献而非资金分配；适合想平滑波动的人；注意低估了股债尾部相关性上升的风险；
3. **全天候思路**：按经济环境四象限（增长/通胀 ↑↓）分散；股、债、商品、黄金各司其职；
4. **核心-卫星**：核心宽基/红利 70–90% + 卫星行业/主题 10–30%（卫星细则见 `03-ETF策略.md`）。

**四类资产的默认角色**（可调）：
- 股票/权益：增长引擎（波动来源）；
- 债券/货币：稳定器与现金流；
- 商品（黄金等）：尾部对冲与通胀保护（不指望收益，指望"不相关"）；
- 现金：期权价值（等待机会 + 心理缓冲）。

## 3. 量化骨架（必须给数字）

- 相关性矩阵：候选资产两两相关（近 3 年滚动 vs 全样本，看相关性是否在危机期上升）；
- 组合层指标：预期波动、最大回撤估算（历史区间 + 压力情景）、回撤恢复时间；
- 压力测试：至少测三类情景——利率快速上行 / 权益快速回撤 20–30% / 相关性普涨（股债商品同跌）；
- 再平衡规则：定期（季度/半年）或阈值（偏离目标 ±5%）先到先执行；写明税费影响。

## 4. 税务、费用、汇率、账户

- 费用：费率每年吃掉多少收益（用差 0.5% 费率 10 年复利差异演示）；
- 税务：不同品类/账户的税负差异；避免频繁再平衡带来的税务拖累；
- 汇率：跨境资产的汇率是独立变量——要么接受波动，要么按需对冲；
- 账户类型：优先在免税/低税账户放高周转资产。

## 5. 输出模板裁剪版

```
【情景判断】定骨架 / 调结构 / 检查现有组合
【目标与约束】目标区间 + 回撤底线 + 期限 + 流动性 + 杠杆
【配置骨架】各类资产比例区间（表）+ 每类承担的角色
【再平衡与执行】频率/阈值 + 执行方式（分批还是一次性）
【压力测试】三类情景下的估算回撤与应对动作
【风险与失效】相关性上升、目标漂移、纪律松懈的识别信号
【备选方案】更保守一档 / 更进取一档（±10–20% 权益）
【下一步】需要补的数据：现有持仓、现金流、应急金、税务环境
```

## 6. 与个股/量化的边界
- 配置层回答"多少仓位给什么"；个股选择归 `02`、量化细节归 `01`、止损执行归 `05/06`——避免越界把配置建议做成"荐股"。
