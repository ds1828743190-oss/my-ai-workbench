# 模块 06 · 交易执行

> 触发情景：用户问"怎么买怎么卖、下单、分批、滑点、执行"。
> 模块目标：让"想到的"和"做到的"之间的损耗最小化。

---

## 1. 订单与执行工具

| 工具 | 适用 | 注意 |
|---|---|---|
| 市价单 | 高流动性、急迫 | 盘口薄时禁用（吃出大价差） |
| 限价单 | 默认首选 | 未成交风险：写明替代方案（改价还是放弃？） |
| 分批/时间切片 | 大额建仓（占日成交量 >1%） | 拆成 N 笔，间隔执行；避免同一时刻累积冲击 |
| 算法执行 | 机构/大额 | 个人一般用"手动分批 + 限价"即可 |

## 2. 分批建仓与退出（与 05 模块的止损体系配套）

- 建仓三档（示例框架，按策略替换）：试探仓 1/3（逻辑确认）→ 确认仓 1/3（走势/数据验证）→ 加码仓 1/3（突破或回调支撑确认）；
- 退出同构：先减一半 → 观察 → 清余仓；**或**按移动止损一次性退出；
- 纪律：每档的价格与条件**事先写下**，盘中只执行不商量。

## 3. 滑点与流动性控制

- 先看三个数：日均成交额、盘口买卖价差、当前挂单深度；
- 经验规则：单笔订单 ≤ 日成交额 1%（保守），激进也不超 5%；超出则必须拆分到多日；
- 记录"假设滑点 vs 实际成交价"偏差——这是策略成本模型校准的关键回馈。

## 4. 交易时段与日历

- A 股：开盘前 15 分钟与收盘前 15 分钟通常波动最大（避开大额市价）；
- 事件窗口（财报、政策发布）前后预设动作：进场还是离场，事先决定；
- 交易日历：节假日前流动性下降；ETF 注意跨境品种的时差与溢价。

## 5. 交易纪律与复盘

- **交易前三问**：这笔的买入逻辑一句写得出吗？证伪条件是什么？最大损失是否可承受？
- 交易日志模板：日期 / 标的 / 方向 / 价格 / 仓位 / **依据（引用策略）** / 情绪自评（1–5）/ 事后复评；
- 月度复盘三指标：执行偏差（计划价 vs 成交价）、纪律违规次数（目标 0）、情绪化交易占比；
- 偏差分析：把每笔亏损归因到"策略错 / 执行错 / 运气"——只有前两类可以改进。

## 6. 输出模板裁剪版

```
【执行方案】建仓/退出分档表：每档价格条件、数量、订单类型
【成本估算】费用 + 预估滑点（按流动性分档）+ 总摩擦成本占仓位比例
【纪律清单】执行前三问 + 盘中只执行不商量
【复盘机制】日志字段 + 月度三指标阈值
```
