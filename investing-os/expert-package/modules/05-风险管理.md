# 模块 05 · 风险管理

> 触发情景：用户问"回撤、仓位、止损、风控、组合安全"。
> 模块目标：把"亏多少"变成事先写好的数字，而不是事后的情绪。

---

## 1. 事前约束（先定上限，再谈买卖）

| 约束 | 建议框架（经验参考，按个人承受力调整） |
|---|---|
| 单标的仓位上限 | 5–15%（个股按可否承受归零设定；ETF 可放宽） |
| 单行业/风格上限 | ≤25–30% |
| 总权益仓位 | 由 `04-资产配置` 的期限与回撤底线倒推；绝不因"这次不一样"临时突破 |
| 杠杆 | 默认=0；使用前必须明确：最大可承受的强平距离、补保能力、利率成本 |
| 流动性底线 | 应急金与投资账户分离；单标的日成交额须远大于自身持仓（如 1% 以内） |

## 2. 止损体系（四类，组合使用）

1. **价格止损**：单笔亏损达到事先设定比例（如 -15%~-25%，取决于波动）；对高波动品种用 ATR 倍数替代固定百分比；
2. **移动止损**：浮盈后上移止损位（如最高价回撤 10–15% 触发），锁定利润但不封死上涨；
3. **时间止损**：买入逻辑有"兑现时限"（如等待某个催化）；时限内逻辑无进展即退出——时间是成本；
4. **逻辑止损（最重要）**：买入的证伪条件触发即走——基本面恶化、增速转负、逻辑被数据推翻。"不设固定止盈止损"不等于不卖（参 `02-股票研究` §6）。

## 3. 风险度量（组合层仪表盘）

- 最大回撤（含回撤持续期与恢复时间——恢复时间比回撤深度更折磨人）；
- 波动率（近 20/60 日，与历史区间比较）；
- VaR / CVaR（历史法即可起步；说明只是估计，不是上限）；
- 压力测试三类：权益 -20~30% 快速回撤 / 利率快速上行 / 相关性普涨；
- 集中度：前三大持仓占比、行业集中度、因子暴露（小盘/动量/成长各有暴露值）。

## 4. 尾部与结构风险（容易被忽略的四条）

1. **相关性上升**：平时分散的组合在危机中可能同涨同跌——压力测试必须用"危机相关性"而非平静期数据；
2. **流动性枯竭**：卖出可能吃大价差/挂在跌停；小盘与冷门 ETF 尤其注意；
3. **杠杆与衍生品**：亏损放大 + 时间价值 + 强平线，任何杠杆方案必须单列风险段；
4. **单一信任点**：单一平台、单一策略、单一数据源都算集中度风险——尤其数据源，重要决策至少两源交叉验证。

## 5. 策略/组合失效条件与退出机制（写死，不临时商量）

- 触发式清单（示例模板，按实际策略替换数字）：
  - 回撤突破历史最大回撤的 **1.2 倍** → 减半仓位并全面复盘；
  - 连续 **N 期**（如 3 个月）滚动指标（IC/夏普）为负且超出历史波动 → 停手评估；
  - 核心前提变化（费率结构、市场规则、参与者结构）→ 重新验证策略前提；
- 退出执行：**事先写清"谁在什么时候以什么价格清掉什么"**；退出后设置冷却期（如 1 个月）防情绪化反手。

## 6. 输出模板裁剪版

```
【风险体检表】仓位结构/集中度/相关性/杠杆 → 逐项红黄绿
【指标仪表盘】当前回撤 vs 历史最大、波动分位、VaR/CVaR 估算
【止损与失效清单】价格/移动/时间/逻辑四条线各自的数值与动作
【压力测试】三类情景下估算亏损与应对预案
【红线】不可突破的三条（例：不杠杆、单票≤10%、退出后冷却期）
```
