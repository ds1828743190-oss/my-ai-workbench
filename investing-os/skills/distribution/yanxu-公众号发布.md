# distribution · yanxu（言序 · 公众号发布）

> 类型：Connector 能力卡 ｜ 来源：研股股 mcp-docs / MCP-工具接入指南
> 定位：把写好的文章推送到微信公众号**草稿箱**——自媒体台三平台分发的公众号渠道；投资晨报/行业综述的发布渠道。

---

## 一、能力与工具清单

| 工具 | 作用 |
|---|---|
| `list_wechat_accounts` | 查当前账号可管理的公众号列表 |
| `list_theme_styles` | 选排版样式主题 |
| `create_article` | 创建文章草稿（传入标题/正文/样式） |
| `publish_article` | 推送草稿（**到草稿箱**，由用户在手机上最终点发布） |

## 二、使用纪律（红线）

1. **不代发布**——本工具链止步于"推草稿箱"；正式发布必须经用户手机端人工确认（与 `workbenches/media/prompt.md` 红线一致）；
2. 数据引用标来源；不追敏感时事；
3. 应用到投资内容时，报告末尾保留统一免责声明；**投资内容发布前过一遍合规口径**（圆桌口径禁指令性结论）；
4. 与本工具链的连接授权绑定各自平台账号，**凭据不写入仓库**。

## 三、接入方式
- WorkBuddy / 支持 MCP 的平台：在连接器管理中接入"言序"并完成授权；
- 自建环境：按接口语义自封装（四个动作即全部能力面）。
