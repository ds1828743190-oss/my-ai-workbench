# 交易分析工作流（trading-analysis）

> 定位：**交易决策收敛系统**。与 `../equity-research/` 的分工：equity-research 产出"研究报告"；本技能把研究报告收敛为"决策"——**必须给出明确 BUY / SELL / HOLD + 入场/目标/止损/仓位**。
> 机制说明（去人格版）：原"多角色辩论"保留为**多立场评审机制**——四个分析维度独立产出、多空两方对抗论证、三方风险视角对抗、两级裁决收敛。执行时**以职能/立场组织**（"技术面分析"而非"某分析师"），不扮演具体人设。

---

## 一、五阶段结构

```
Phase 1  四维分析【并行】   技术面 / 基本面 / 新闻面 / 情绪面 —— 四路独立产出，互不可见
        ↓  4 份报告
Phase 2  多空论证【顺序】   多头论证 → 空头论证 → 裁决出 [投资计划]
        ↓  （深度模式：多空可互相回应进行第 2 轮）
Phase 3  交易方案【单一】   [交易员决策]：FINAL TRANSACTION PROPOSAL + 价位/仓位
        ↓
Phase 4  风险评审【并行+顺序】
        4.1 三方视角【并行】激进 / 保守 / 中性 —— 三路独立论证
        ↓  3 份风险论证
        4.2 裁决【顺序】 → [最终交易决策]（风险调整后 BUY/SELL/HOLD + 仓位）
        ↓
Phase 5  汇编报告【单一】   五段式报告 + HTML 可视化
```

**并行纪律**：Phase 1（4 路）与 Phase 4.1（3 路）立场独立、无数据依赖——**必须并行**（顺序执行等于后者偷看前者答案，多视角价值归零）；Phase 2/3/4.2 有上下游依赖——**必须顺序，传递原文**（不是摘要）。

## 二、两种执行方案（按环境选择）

| 方案 | 适用 | 做法 |
|---|---|---|
| **A · 单代理顺序执行**（默认） | 个人环境/单 AI 会话 | 一个代理按阶段依次产出，每阶段结束**切换立场重读**（先以多头立场写论证、再以空头立场批判，明确"立场切换"以免同质化）；产物标记照常输出 |
| **B · 多代理并行** | 支持子代理/TeamCreate/多任务的环境 | Phase 1 与 Phase 4.1 各开启多个独立子任务并行；派单时传入「标的 + 共享快照 + 数据通道状态 + 对应阶段卡」；子任务命名用**职能 ID**（如 `phase1-technical`、`phase4-conservative`，kebab-case 英文），不带人名 |

**共享快照**：调度前取 1 次行情快照（代码/现价/涨跌幅/PE），注入全部任务；等待期间不重复取数。
**执行预算**（单路）：取数 ≤4 次；报告 800–1500 字；写完即产出，禁止边写边查。

## 四、执行模式（按用户问法）

- **完整模式（默认）**：5 阶段全跑（"帮我分析 XX 该不该买"）；
- **快速模式**：仅 P1（技术面 + 基本面两路）→ P3 → P5（"快速分析"）；
- **辩论模式**：用户已提供数据/报告 → 跳过 P1，跑 P2–P5；
- **单一维度直调**：只问 K 线→仅出 `[市场技术分析报告]`；只问财报→仅出 `[基本面分析报告]`；只问资金→仅出 `[情绪分析报告]`；已有结论只要方案→直接 P3。

**HTML 可视化（图表规范）**：自包含单文件（CSS/JS 内联、零后端），四类图——综合评分雷达图（技术/基本/情绪/风险四维）、价格走势图（均线+支撑压力标注）、多空论点对比图、风险三角图；文件名 `[代码]-analysis-report-[日期].html`；渲染可交 `../md-to-html/` 或按此规范直接产出。

## 六、裁决纪律（两级，写死）

1. 研究裁决与风险裁决**必须给出明确方向**；禁止以"双方都有道理"为由默认 Hold；
2. **Hold 的适用条件**：仅当存在明确的"等待更好时机"理由（重大事件在即、当前风险收益比不划算）——不作为回避表态的默认项；
3. 风险裁决的最终方案**可以调整交易方案原案**（价位/仓位/节奏），需写明调整理由；
4. 交易方案须计算**盈亏比（建议 ≥2:1）**并以技术位设置止损，体现风险控制。

## 七、数据与合规

- 取数走 `../data-layer/`（契约与纪律）与 `../../mcp-guide/`（MCP 接入/工具调用）；同一流程内单源不混用；数字标来源与日期；
- 技术指标基于日线自行计算；不编造行情/财报；
- 不承诺收益；对杠杆/衍生品/跨境等高风险内容单列提示；条件化表达（"若 A 发生→执行 B"）；
- 全套产物末尾附统一免责声明；涉及个人动作建议回到工作台固化规则复核。
