# 阶段卡 04 · 三方风险评审与裁决（Phase 4）

> 使用方式：`[交易员决策]` 产出后加载。先三路并行评审（激进/保守/中性），再顺序裁决。
> 注意：三种视角是**审阅立场**，用于穷尽风险光谱，不是角色扮演——写作时说"从激进视角看……"，不写"我是XX分析师"。

---

## 一、三路评审（Phase 4.1，并行）

输入（三路相同）：`[交易员决策]` + `[投资计划]` + 四份报告 + （单代理时）已产出的前两路论证。

### 1.1 激进视角 → `Aggressive Analyst: [激进派论证]`
目标：为高回报机会辩护。
1. 强化上行论据（技术突破/资金流入/基本面加速/催化剂临近）；
2. 挑战过度谨慎——量化"错失机会"的成本；
3. 逐条反驳保守/中性风险点：概率低 / 已定价 / 有对冲；
4. 推动果断：若方案为 Hold，论证为何当前是较好入场时机；若为 Buy，论证是否可加仓。
**边界**：论点必须有数据支撑；承认真实风险存在，论证回报潜力超过风险成本。

### 1.2 保守视角 → `Conservative Analyst: [保守派论证]`
目标：揭示被低估的风险。
1. 识别最脆弱的假设与最大不确定性；
2. **量化下行**：具体情景下亏损多少、概率几何（拒绝"风险很高"式空话）；
3. 批判乐观假设的成立条件；
4. 提出更审慎替代（更低价位入场/减仓/等事件确认）并论证其风险调整收益更好；
5. 关注尾部风险（监管/黑天鹅/流动性——低概率高毁灭）。
**边界**：不是否定价值，而是呼吁更审慎的执行方式；风险可控时可支持小仓位版本。

### 1.3 中性视角 → `Neutral Analyst: [中性派论证]`
目标：在两极之间找更优操作方案。
1. 批判激进偏颇（哪些风险被合理化、乐观落空损失多大）；
2. 批判保守偏颇（等待的机会成本、哪些风险已定价）；
3. 整合**更广视角**（市场趋势/宏观周期/板块轮动/仓位管理）；
4. 推荐温和策略：分批建仓、动态止损、事件前留弹药——给出具体仓位与节奏。
**立场价值**：论证"两极之间存在更优路径"，不是和稀泥。

## 二、裁决（Phase 4.2，顺序）→ `[最终交易决策]`

输入：三方论证 + `[交易员决策]` + `[投资计划]` + 四份报告。

**三步裁决**：

1. **提炼**：各视角 1 个最有说服力的核心论点（各 1 句），评估数据质量与逻辑严密性；
2. **判断方向**：哪方立场在当前环境下最具相关性——
   - 激进+中性的上行论据更强 → 倾向 **Buy**；
   - 保守的下行论据更强 → 倾向 **Hold / Sell**；
   - **Hold 条件**：仅当存在明确的"等待更好时机"理由（重大事件在即、风险收益比不划算）——不作默认选项；
3. **输出风险调整后的最终方案**（可在交易员原案基础上调整）：

```
最终决策：[Buy / Sell / Hold]
核心裁决理由：采纳了哪个视角的哪个论点（具体内容 + 为何最有说服力）
最终操作方案（调整自交易员原方案）：
- 入场价位：[区间]（是否调整 + 原因）
- 目标价位：[价格]（依据）
- 止损价位：[价格]（风控依据）
- 建议仓位：[X%]（较原方案的调整说明）
- 操作节奏：[一次性/分批 + 说明]
- 关注触发点：[加仓条件] / [减仓/止损条件]
```

产出标记：`[最终交易决策]`

---

**纪律**：裁决必须明确（不许模糊）；允许"调整原方案"，但每处调整写明理由；尾部风险若不可控须直说（使风险显性化也是结论的一部分）。
