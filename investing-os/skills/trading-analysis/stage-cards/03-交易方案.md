# 阶段卡 03 · 交易方案（Phase 3，单一）

> 使用方式：`[投资计划]` 产出后加载本卡。产出 `[交易员决策]`，核心是 **FINAL TRANSACTION PROPOSAL**。

---

## 一、输入

- `[投资计划]`（核心参考）｜ `[市场技术分析报告]`（入场时机）｜ `[基本面分析报告]`（价值支撑）｜ `[新闻分析报告]`（催化剂/风险）｜ `[情绪分析报告]`（短期情绪）

## 二、决策框架（五步）

1. **计划复核**：以 `[投资计划]` 为基础，判断其逻辑当前是否仍然成立（数据有无变化）；
2. **时机验证**：技术形态是否支持立即行动——入场信号出现否（趋势/突破/回踩确认）？未出现则给出等待条件；
3. **风险收益评估**：基于技术位设定止损，计算潜在盈亏比——**建议 ≥2:1**；低于该值时说明调整方向（等更好价位/缩小仓位/放弃）；
4. **催化剂检查**：近期有无重要事件（财报/政策发布）——事件前建仓需减半仓位或等待确认；
5. **情绪验证**：市场情绪与决策方向是否一致；背离时说明处理（降仓/分批）。

## 三、操作细节（决策为 BUY 或 SELL 时必填）

- **入场价**：区间 + 依据（技术位/估值位）；
- **目标价**：依据（阻力位/估值目标）；
- **止损价**：依据（关键支撑位）——体现风险控制纪律；
- **仓位**：占组合比例参考 + 操作节奏（一次性/分批）。

## 四、输出格式（固定结尾）

分析正文之后，**必须以如下格式结束**：

```
FINAL TRANSACTION PROPOSAL: **BUY** / **SELL** / **HOLD**
```

最后一行产出标记：`[交易员决策]`

---

**纪律**：不给出无法执行的价格（"大约"不算）；盈亏比必须显式计算；HOLD 时须说明"等什么条件、到什么价位再评估"。
