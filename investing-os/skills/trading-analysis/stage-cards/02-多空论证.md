# 阶段卡 02 · 多空论证与裁决（Phase 2，顺序）

> 使用方式：Phase 1 四份报告收齐后加载。三个环节**顺序执行**、**原文传递**（非摘要）。
> 单代理执行时：先以多头立场完整撰写 → 再以空头立场批判撰写 → 最后切回中立裁决——每次立场切换必须显式声明，防止同质化。

---

## 一、多头论证 → `Bull Analyst: [多头论证]`

输入：`[市场技术分析报告]` + `[基本面分析报告]` + `[新闻分析报告]` + `[情绪分析报告]`（深度模式第 2 轮另加空头上轮反驳）。

四个构建方向：
1. **增长潜力**：市场机会、营收增长预测、业务可扩展性——用具体数字（增长率、市场规模）支撑；
2. **竞争优势**：品牌/技术/份额/成本/网络效应等难以复制的壁垒；
3. **积极信号汇聚**：技术面（趋势/突破/量价）+ 情绪面（资金流入/评级上调）+ 新闻面的多维共振；
4. **反驳空头风险**：预判核心风险并论证其被高估或已被定价。

表达要求：对话式、有说服力；引用四份报告的具体数据；聚焦 2-3 个最强论据；第 2 轮必须逐条回应空头。

## 二、空头论证 → `Bear Analyst: [空头论证]`

输入：四份报告 + 多头论证（**必须直接反驳**）。

四个构建方向：
1. **核心风险**：财务脆弱点（负债率、现金流恶化、毛利下滑、应收激增）并量化程度；
2. **竞争劣势**：份额侵蚀、产品力下降、管理层不稳、监管收紧——格局恶化趋势；
3. **负面信号汇聚**：技术破位/放量下跌/死叉 + 资金持续流出/评级下调/融资余额下降；
4. **反驳多头乐观假设**：找出多头论点依赖的假设，用数据说明假设不成立或过于激进。

表达要求：对话式、有攻击性；引用具体数据；聚焦 2-3 个最破坏性的下行风险；第 2 轮必须逐条回应多头。

## 三、裁决 → `[投资计划]`（研究裁决）

输入：多空论证（含第 2 轮）+ 四份报告（补充验证）。

**必须完成三件事**：
1. **总结双方最强论点**：多头 1-2 个（各 1 句）+ 空头 1-2 个（各 1 句）——聚焦证据质量而非论证技巧；
2. **给出明确决策**：Buy / Sell / Hold；
   - ⚠️ **禁止**以"双方都有道理"为由选 Hold；
   - **Hold 仅适用**：标的处于关键事件等待期（业绩发布/重大政策落地），且当前价格已充分反映已知信息；
   - 必须基于质量最高的证据给出倾向性立场；
3. **制定投资计划**：

```
建议：[Buy / Sell / Hold]
核心理由：哪方哪个论点最有说服力、为何选这侧
策略行动：
- 入场/出场价位区间：[区间]（依据：技术位/估值位）
- 仓位参考：轻(<30%) / 中(30-60%) / 重(>60%)（依据：风险收益比）
- 关键催化剂：触发加仓/减仓的正面事件
- 关键风险事件：需止损/减仓的负面触发条件
```

---

**纪律**：全文引用具体数据；裁决不得含糊；产物标记单独成行。
