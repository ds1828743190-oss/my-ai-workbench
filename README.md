# my-ai-workbench · 个人 AI 工作台操作系统

> 以我固化的投资策略与提示词为**宪法**，以蒸馏自五个外部专家系统的人格/编排/技能为**智囊团**，
> 以演化层持续沉淀个人风格的**个人 AI 工作台**——可发布、可跨环境复用、可持续增厚。

---

## 这是什么（不是一份文档，是一座七层文件工程）

| 层 | 位置 | 作用 | 规模 |
|---|---|---|---|
| **L0 宪法层** | `workbenches/` | 定义"我是谁、按什么规则做事"——跨平台最小可用内核 | 14 文件 |
| **L1 人格层** | `investing-os/experts/` | 每个 md 是一个可独立加载的"专家脑" | 51 文件（19 大师 + 19 分析师 + 6 圆桌 + 6 主理人/管理 + 索引） |
| **L2 编排层** | `investing-os/workflows/` | 多智能体怎么协作——5 张卡（4 模式 + A股路由） | 6 文件 |
| **L3 技能层** | `investing-os/skills/` | 交付物技能 / 数据层 / 渲染管线 / 分发工具 | 34 文件 |
| **L4 量化工具层** | `quant-tools/` | 可本地真实运行的 Python 工具链（GPL-3.0） | 44 文件 |
| **L5 演化层** | `personal/` | 观点蒸馏卡 + 策略候选区（越用越像"我"） | 3 文件起步 |
| **L6 文档档案层** | `docs/` | 移植指南归档、plugin 清单、设计文档、核对表 | 36 文件 |

## 一次典型使用（文件如何流转）

"帮我看看中际旭创" → L0 兜底（环境自检/红线）→ 命中路由 → 加载 L2 `roundtable-parallel`（6 人并行 + 主理人汇编）→ 注入 L1 六份圆桌人格 → 按 L3 data-layer 纪律取数 → 汇编报告经 L3 `md-to-html` 渲染成分享页 → 若想验证策略设想，过 L4 三关（复现 → 过拟合守门 → tearsheet）→ 新想法回写 L5。

## 快速开始

1. **轻环境（任何 AI）**：打开 `workbenches/investment/prompt.md`，整段复制粘贴到首条消息（或系统提示栏）→ 发「环境自检」→ 开始用；
2. **WorkBuddy**：`investing-os/skills/` 各技能按需拷入 `~/.workbuddy/skills/`；`experts/` 人格作子代理提示词；
3. **Claude Code**：核心提示词入 `CLAUDE.md`；`quant-tools/` 各技能自带 `agents/portable-loader.md` 装载说明；
4. **想看体系全貌**：`docs/设计文档-移植内容整合方案-v1.2.md`（本仓库的设计蓝图与演进日志）。

## 核心原则

1. **核心轻，外重重**——L0 永远轻到"一段提示词走天下"；重资产沉在 L1-L4，按需加载；
2. **按层切，不按包搬**——外来专家包先拆成"人格/编排/技能"三类原料再入库；
3. **宪法优先**——所有智能体产出最终都要回到股债利差区间规则复核；演化走"蒸馏卡→候选区→月度复盘→转正"；
4. **诚实降级**——数据取不到就标注降级，绝不编造。

## 合规与安全

- 全部输出仅为研究参考，**不构成投资建议**；统一免责声明随各报告输出；
- 仓库只含模板、方法与提示词；真实持仓/交易数据、个人档案、凭据 token 一律不入库（见 `.gitignore`）；
- `quant-tools/` 三个技能为 GPL-3.0，LICENSE 与来源声明随包保留，不得移除。
