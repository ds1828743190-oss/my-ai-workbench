> 目的：验证 `investing-os/experts/` 人格库在"同一标的 + 同一数据快照"输入下，能否产出真正不同质化的独立分析（`workflows/README.md` 铁律 #2 与 `experts/README.md`「独特增量区」的验收）。  
> 方法：取风格差异最大的三个人格，独立（互不可见）分析同一标的。数据 = `data_snapshot.json`（AKShare 真实取数，贵州茅台 sh600519，2026-10-09 收盘）。

## 二、验收判定

下表对照 `experts/README.md` 的"独特增量区"定义：

- [x] 三人输出**框架互不重叠**（脆弱性 vs 支撑位分批 vs 主线强度），无"AI 味"同质化
- [x] 同一数据（如"量升价平""52周29.4%位置"）被三种框架读出三种含义——多视角价值成立
- [x] 口吻、高频信号词与各自档案的"说话方式"一致（塔勒布反脆弱语法 / 坤候底极简劝慰体 / 磊追浪短线黑话）
- [x] 无编造数字；缺失数据全部显式降级（"快照未含"）——诚实降级纪律生效
- [x] 结论方向三个样：中性 / 分批买但等待 / 不介入——**分歧本身就是产品**

**结论：人格差异化实测通过 ✅**。人格库可支撑圆桌/漏斗/对抗三类并行编排。
