# MCP / 数据接入指南 · 投资大师专家团

> 本专家团**只依赖一个数据源**：`neodata-financial-search`（NeoData 金融数据服务）。
> 本文件说明它的接入方式，以及移植到你自己的工作台时的三条替代路线。

---

## 一、这个数据源是什么

`neodata-financial-search` 是一个**自然语言金融数据召回服务**——输入一句中文/英文问题，返回结构化金融数据 + 文档型内容（研报/公告/资讯）。覆盖七大类：

| 大类 | 覆盖范围 |
|---|---|
| **股票** | A股 / 港股 / 美股 / 日股 / 韩股——行情、财报三表、复合财务指标、资金流向、股东、分红、龙虎榜、两融、大宗交易 |
| **指数** | 主要指数行情、成分股、估值百分位、大盘统计 |
| **板块** | 板块成分、实时行情、资金流向、估值、热点驱动原因 |
| **公募基金** | 净值、业绩、回撤、持仓、规模、基金经理画像、基金公司 |
| **宏观经济** | 全球/中国 GDP、CPI、PMI、M2、社融、经济事件日历 |
| **外汇** | 人民币中间价、主要货币对实时汇率、美元指数 |
| **大宗商品** | 黄金现货、贵金属/能化/农产品/利率/基本金属期货行情 |

时效覆盖**实时**与**历史长周期**（A股 1990 起 / 港股 1980 起 / 美股 1950 起）。

## 二、原始调用方式（WorkBuddy 内）

服务端点是**代理形式**：

```
POST https://copilot.tencent.com/agenttool/v1/neodata
Header: Authorization: Bearer <凭证>
Header: Content-Type: application/json
Body:  { "query": "自然语言问题", "channel": "neodata", "sub_channel": "workbuddy" }
```

- `channel` / `sub_channel` 为固定字段，必须显式传入
- `data_type` 可选：默认不传 = `all`（结构化 API + 文档一并召回，推荐）；`api` 仅结构化；`doc` 仅文章

技能包内已封装好两个取数脚本（**可直接复用**）：

```bash
# Python（推荐，3.7+，缺 requests 会退化到标准库 urllib）
python3 scripts/query.py --query "腾讯最新财报"

# Shell（备选，curl 封装，自动探测 python3/python/py）
bash scripts/query.sh "贵州茅台股价"
```

响应核心在 `data.apiData`（结构化召回：entity + apiRecall）与 `data.docData`（文档召回：docRecal）。

## 三、鉴权机制（⚠️ 这是移植的关键障碍）

原技能的鉴权是**两步走 + 本地缓存**：

```
1. 先直接查询 → 脚本读本地缓存 .neodata_token（12 小时有效）
2. 缓存缺失/过期 → 脚本输出 TOKEN_EXPIRED / TOKEN_MISSING
3. 此时调用 WorkBuddy 专用工具 connect_cloud_service 取临时凭证（tempToken 优先，token 兜底）
4. 用 --save-token "<凭证>" 写入缓存文件，再重新查询
```

**为什么不能整包搬走**：第 3 步的 `connect_cloud_service` 是 **WorkBuddy 平台专属通道**，凭证绑定你的 WorkBuddy 账号会话。在外部平台上这一步无法复现，脚本本身也不含任何硬编码密钥（这是好事——包里没有泄露任何凭据，可放心分享）。

## 四、移植时的三条替代路线

### 路线 A：向数据服务商申请独立凭据（最接近原体验）

向腾讯 NeoData / 恒生聚源等数据服务商申请独立 API 接入，拿到 endpoint 与长期 token 后：
- 把 `scripts/query.py` 的 `DEFAULT_ENDPOINT` 与鉴权来源改掉（或把 token 写进你自己的密钥管理）
- 请求结构与响应解析逻辑**无需改动**

### 路线 B：换开源数据源（无凭据时首选）

用开源库自建一个等价的数据获取层，把 `SKILL.md` 里的"调用步骤"替换即可：

| 原能力 | 开源替代 |
|---|---|
| A股/港股/美股行情、财报、资金流 | **AKShare**（覆盖面最广，免费） |
| A股财务、行情、指数 | **Tushare**（需积分） |
| 板块/资金/龙虎榜/两融 | **东方财富**公开接口 |
| 美股行情/财报 | yfinance |

> 关键：**20 份成员提示词完全不依赖具体数据源**，只依赖"能否拿到行情 / 财务 / 资金 / 新闻"。换源后只需改写这一个技能的调用封装。

### 路线 C：复用其他已授权连接器

若你的工作台已接入 **dzh-mcp（大智慧）** 或 **腾讯自选股（westock-mcp）**，可把它们当作数据层——但注意：这些同样是绑定 WorkBuddy 账号的官方连接器，直接搬到外部平台仍需各自的独立凭据。

> 另两个移植包（`研股股-专家移植包`、`投研专家团-移植包`）中附有这两个连接器的完整使用文档，可交叉参考。

## 五、接口错误码（对接时容错用）

| code | msg | 处理 |
|---|---|---|
| `1001` | 未命中意图 | 改写 query，更具体 |
| `1616039101` | 参数值不合法 | 检查入参 |
| `1006` | 查询解析拒答 | 策略拦截/不支持场景，换问题 |
| HTTP 401/403 或 `40101` | 凭证失效 | 重取一次凭证；两次失败即判服务不可用，停止重试 |

## 六、落地清单

1. 先跑通"一句自然语言 → 拿到行情/财务"的最小闭环（路线 B 最快）
2. 把 `scripts/query.py` 的请求/响应结构作为接口契约参考
3. 在成员提示词的"数据获取"步骤里，把工具名替换为你的封装
4. 保留"数据来源标注"与"不编造数字"两条纪律——这是投研可信度底线
