# MCP / 数据接入指南 · 交易分析团队

> 本团队**只依赖一个数据源**：`neodata-financial-search`（NeoData 金融数据服务）。
> 本文件说明它的接入方式，以及移植到你自己的工作台时的三条替代路线。
> 随包副本位于 `data-source/neodata-financial-search/`（SKILL.md + reference.md + 两个取数脚本）。

---

## 一、这个数据源是什么

`neodata-financial-search` 是一个**自然语言金融数据召回服务**——输入一句中文/英文问题，返回结构化金融数据 + 文档型内容（研报/公告/资讯）。覆盖**十大类 + 辅助类**：

| 大类 | 覆盖范围 |
|---|---|
| **股票** | A股 / 港股 / 美股 / 英股 / 日股 / 韩股——行情报价、盘口、财报三表、复合财务指标、资金流向、股东、分红回购、龙虎榜、两融、大宗交易、业绩会议纪要 |
| **指数** | 主要指数行情、成分权重、行业分布、估值百分位、盈利预测、指数资金流 |
| **板块** | 板块成分股、ETF、实时行情、资金排行、异动、估值、热点驱动原因 |
| **公募基金** | 净值、业绩、回撤、持仓、规模、分红、基金经理画像、基金公司、REITs |
| **债券** | 一般债/可转债行情、估值、收益率曲线、付息现金流、信用评级、债券指数 |
| **期货** | 境内商品/金融期货历史行情、会员持仓排名、仓单交割、海外股指期货实时行情 |
| **期权** | 合约行情、希腊字母、交易持仓统计、合约规则 |
| **宏观经济** | 全球/中国 GDP、CPI、PMI、M2、社融、利率、经济事件日历 |
| **外汇** | 人民币中间价、主要货币对实时汇率、美元指数 |
| **大宗商品** | 品牌黄金报价、上海金/伦敦金等贵金属现货、各类期货行情 |

辅助数据：**研报评级/目标价、盈利预测、舆情社媒观点、财经新闻快讯、市场交易日历**。

时效覆盖**实时**与**历史长周期**（A股 1990 起 / 港股 1980 起 / 美股 1950 起）。共 **130+ 数据工具**。

> 对本团队的实际用法：Phase 1 的 4 位分析师各取自己那一维度的数据（技术面要 OHLCV 日线、基本面要三表与估值、新闻面要公告与宏观事件、情绪面要资金流与机构评级）；技术指标（SMA/EMA/MACD/RSI/布林带/ATR）**由分析师基于返回的日线数据自行计算**，服务不直接给指标。

## 二、原始调用方式（WorkBuddy 内）

服务端点是**代理形式**：

```
POST https://copilot.tencent.com/agenttool/v1/neodata
Header: Authorization: Bearer <凭证>
Header: Content-Type: application/json
Body:  { "query": "自然语言问题", "channel": "neodata", "sub_channel": "workbuddy" }
```

- `channel` / `sub_channel` 为**固定必填**字段，必须显式传入
- `data_type` 可选：默认不传 = `all`（结构化 API + 文档一并召回，**推荐**）；`api` 仅结构化；`doc` 仅文章
  - ⚠️ 纪律：不要为了"减小返回体积"而默认加 `api`——实测会让 20–40% 本可由文章召回兜底的 query 变成空结果

技能包内已封装好两个取数脚本（**可直接复用**）：

```bash
# Python（推荐，3.7+，缺 requests 会自动装或退化到标准库 urllib）
python3 scripts/query.py --query "腾讯最新财报"
python3 scripts/query.py --query "贵州茅台 近6个月历史行情数据 日线 开盘收盘最高最低成交量"

# Shell（备选，curl 封装，自动探测 python3/python/py）
bash scripts/query.sh "贵州茅台股价"
```

响应核心在 `data.apiData`（结构化召回：`entity` + `apiRecall`）与 `data.docData`（文档召回：`docRecall`）。成功时 `code` 为 `"200"`、`suc` 为 `true`。

## 三、鉴权机制（⚠️ 这是移植的关键障碍）

原技能的鉴权是**两步走 + 本地缓存**：

```
1. 先直接查询 → 脚本读本地缓存 .neodata_token（12 小时有效）
2. 缓存缺失/过期 → 脚本输出 TOKEN_EXPIRED / TOKEN_MISSING
3. 此时调用 WorkBuddy 专用工具 connect_cloud_service 取临时凭证（tempToken 优先，token 兜底）
4. 用 --save-token "<凭证>" 写入缓存文件，再重新查询
```

**为什么不能整包搬走**：第 3 步的 `connect_cloud_service` 是 **WorkBuddy 平台专属通道**，凭证绑定你的 WorkBuddy 账号会话。在外部平台上这一步无法复现。好消息是——**包里不含任何硬编码密钥**，可放心分享。

## 四、移植时的三条替代路线

### 路线 A：向数据服务商申请独立凭据（最接近原体验）

向腾讯 NeoData / 恒生聚源等数据服务商申请独立 API 接入，拿到 endpoint 与长期 token 后：
- 把 `scripts/query.py` 的 endpoint 与鉴权来源改掉（或把 token 接进你自己的密钥管理）
- 请求结构与响应解析逻辑**无需改动**

### 路线 B：换开源数据源（无凭据时首选）

用开源库自建一个等价的数据获取层，把 `SKILL.md` 里的"调用步骤"替换即可：

| 原能力 | 开源替代 |
|---|---|
| A股/港股/美股行情、财报、资金流 | **AKShare**（覆盖面最广，免费） |
| A股财务、行情、指数 | **Tushare**（需积分） |
| 板块/资金/龙虎榜/两融/大宗交易 | **东方财富**公开接口 |
| 美股行情/财报 | yfinance |
| 历史长周期 K 线 | AKShare / yfinance / Stooq |

> 关键：**13 份角色提示词完全不依赖具体数据源**，只依赖"能否拿到行情 / 财务 / 资金 / 新闻"。换源后只需改写这一个技能的调用封装。

### 路线 C：复用其他已授权连接器

若你的工作台已接入 **dzh-mcp（大智慧）** 或 **腾讯自选股（westock-mcp）**，可把它们当作数据层——但注意：这些同样是绑定 WorkBuddy 账号的官方连接器，直接搬到外部平台仍需各自的独立凭据。

> ⚠️ 本团队有"**唯一数据源**"纪律（禁止混源，防口径不一致引发幻觉）。若你换源，请**整体替换**而不是混用多家；确需交叉印证时，至少要在产出中标注每项数字的来源。

## 五、接口错误码（对接时容错用）

| code | msg | 处理 |
|---|---|---|
| `1001` | 未命中意图 | 改写 query，更具体 |
| `1616039101` | 参数值不合法 | 检查入参 |
| `1006` | 查询解析拒答 | 策略拦截/不支持场景，换问题 |
| HTTP 401 / 403 或 `40101` | 凭证失效 | 重取一次凭证；两次失败即判服务不可用，停止重试 |

## 六、落地清单

1. 先跑通"一句自然语言 → 拿到行情/财务"的最小闭环（路线 B 最快）
2. 把 `scripts/query.py` 的请求/响应结构作为接口契约参考
3. 在 13 份角色提示词的"数据获取"段落里，把工具名替换为你的封装（**注意：Phase 1 四位分析师都要各取一次数，建议主理人先取一份共享快照注入，避免重复取数**）
4. 保留"数据来源标注""不编造数字""低置信度标注"三条纪律——这是投研可信度底线
