# 🏗️ 三个个人工作台搭建指南

> 核心原则：**先跑起来，再变强**。每个工作台都分三阶段：表格跑通（第1周）→ 自动化加持（第2-4周）→ 需要时才上数据库/SQL。不搞过度工程。

---

## 〇、先回答你的问题：要不要 SQL、连接器？

| 层 | 是什么 | 你现在需要吗 |
|---|--------|-------------|
| **数据层** | 表格 / 数据库（SQL） | 第 1 阶段全部用**表格**，SQL 留到数据量大了再上 |
| **技能层** | WorkBuddy 内置技能（金融数据、文档、表格、浏览器） | ✅ 立刻用，这是主力 |
| **连接器层** | 外部平台对接（已接：**大智慧MCP** 金融数据、**言序** 公众号发布） | ✅ 已接好两个，按需加 |
| **自动化层** | 定时任务（每天/每周自动执行） | ✅ 第 2 周开始加 |

**SQL 的正确时机**：当你需要 ①手机随手记账 ②数据自动联动（如自动算每个 SKU 利润率）③单量超过几百条频繁写入 时，再做一个轻量网页应用（云服务自带 SQL 数据库，AI 直接帮你建表写查询）。在那之前，SQL 是多余的复杂度。

**闲鱼特别注意**：闲鱼没有官方开放接口，没有任何正规连接器。第三方爬虫/自动上架工具有封号风险，**不建议用**。闲鱼工作台的正解是「AI 辅助 + 手动执行」。

## 一、💰 个人投资工作台

### 你已有的资产（直接复用）
- **股债利差策略**：沪深300股债利差 >6% 定投红利ETF / <4% 减仓换国债ETF（10月10日已成文）
- 巴菲特指标交叉验证、1500元起步复利演示需求

### 模块设计（4件套）
1. **策略卡**：把规则固化成一页 checklist（触发阈值→动作→数据源），防止情绪化操作
2. **持仓台账**：一张 Excel——持仓表 + 交易记录表 + 月度净值表
3. **信号看板**：股债利差、巴菲特指标，每天自动算好
4. **交易日志**：每次买卖记录「为什么买/卖」，月底 AI 复盘

### 搭建流程
```
第1周（约1小时，一次对话完成）
├─ ① 生成《投资台账.xlsx》：三个 Sheet（持仓/交易记录/净值曲线），公式预置
├─ ② 用金融数据技能拉当前股债利差 + 巴菲特指标 → 生成第一份《策略信号卡》
└─ ③ 固化策略卡：>6%做什么、<4%做什么、4%~6%观望

第2周
└─ ④ 建自动化：每个交易日 17:30 自动拉数据 → 判断阈值 → 推送简报
   （"今日股债利差 X%，处于【定投/观望/减仓】区间，持仓浮盈 Y%"）

每月
└─ ⑤ 月度复盘：AI 汇总交易日志，输出"执行纪律评分 + 复利进度"
```

### 用到的技术栈
- 数据源：**大智慧MCP 连接器**（已连接）+ 本地金融技能（westock-data 等）
- 台账：本地 Excel，AI 随时读写分析（表格技能）
- 自动化：WorkBuddy 定时任务
- SQL：**暂不需要**。等你想要"手机随手记交易 + 自动联动行情"时，升级为云数据库版

## 二、🎬 自媒体工作台

### 你已有的资产（直接复用）
- 赛道已锁定：**行为经济学+心理学概念科普**（信号传递、信息不对称）+ 公考经验
- 素材库现成：灵感碎片知识库的每条「拓展方向」都是一个选题（税负三部曲、五问法、机会成本……至少 20 篇的量）
- 工作流设想：每天写想法 → AI 整合 → 周更成文 → AI 生成视频

### 模块设计（4件套）
1. **选题库**：Obsidian 建一个 `自媒体/选题池.md`，每条选题 = 标题 + 核心概念 + 素材链接 + 状态（池中/写作中/已发）
2. **内容流水线**：碎片 → 草稿 → 排版成文 → 推公众号草稿箱 → 发布
3. **数据追踪表**：各平台阅读/粉丝/互动/涨粉，每周填一次
4. **周报自动化**：每周日晚 AI 整合本周碎片 → 生成下周选题 + 数据周报

### 搭建流程
```
第1周（约2小时）
├─ ① 从灵感知识库提取首批 10 个选题，建选题池
├─ ② 写账号定位一页纸（人设/赛道/目标读者/更新节奏）
└─ ③ 定爆款结构模板：现象→本质→启发（你8月31日已总结的框架，直接用）

第2周（跑通第一条最小闭环）
├─ ④ 选1个最熟的选题（建议：税负感知 or 机会成本）写第一篇
├─ ⑤ 用文档技能排版美化 → 言序连接器一键推公众号草稿箱 → 你手机上点发布
└─ ⑥ 发完立即复盘：哪些环节卡了，写进流程备注

第3-4周
├─ ⑦ 图文稳定周更 2 篇后，启动视频流：AI 生成分镜脚本 → AI 生图/视频 → 剪辑
└─ ⑧ 数据追踪表上线，每周日晚自动生成周报
```

### 用到的技术栈
- 发布：**言序连接器**（已连接，AI 写好直接进公众号草稿箱，省掉排版时间）
- 写作排版：文档技能（Markdown → 精美 Word/公众号排版）
- 视频：AI 生图/生视频（WorkBuddy 内置 ImageGen/VideoGen；需要更高质量再接可灵等连接器）
- 选题与知识：Obsidian + 每日灵感整理自动化
- SQL：**不需要**。数据追踪用表格足够

## 三、📦 闲鱼倒卖工作台

### 关键认知
- 无官方接口、无正规连接器 → 一切自动化以「AI 辅助人工」为边界
- 你的核心数据资产是 **SKU 台账**：进价、售价、利润率、周转天数——这是决定赚不赚钱的命脉

### 模块设计（4件套）
1. **选品调研表**：品类、闲鱼成交价区间、进货渠道、预估利润率、周转天数
2. **SKU 台账**：编号/品名/成本/上架日期/状态(在售·已售)/标价/成交价/运费/**净利润**
3. **文案工坊**：拍照丢给 AI → 生成 3 版标题+描述（过敏感词、带钩子）
4. **利润仪表盘**：月度利润、回款周期、爆品排行（表格技能自动算+出图）

### 搭建流程
```
第1天（半小时）
└─ ① 生成《闲鱼台账.xlsx》：选品表 + SKU台账 + 利润仪表盘（公式预置）

第1周（用自家闲置练手，零风险跑通全流程）
├─ ② 挑 3-5 件闲置 → 拍照 → AI 生成文案 → 上架
├─ ③ 成交后回台账记账 → 让 AI 算出真实利润率（扣运费、平台成本）
└─ ④ 复盘：哪一步最耗时 → 下轮优化

第2-4周（正式运营）
├─ ⑤ 锁定 1-2 个类目（选你懂的、单价50-200、周转快的）
├─ ⑥ 每天固定 30 分钟：上新 3-5 个链接 + 擦亮 + 回消息
└─ ⑦ AI 辅助定价：把同款在售价格截图丢给 AI，给出定价建议区间

每月
└─ ⑧ AI 出月度报告：净利润、ROI、周转率、该砍掉的品类
```

### 用到的技术栈
- 台账：Excel + 表格技能（自动算利润、出图表）
- 文案/定价：对话式 AI（拍照描述 → 3 版文案 + 定价区间）
- 选品调研：浏览器技能人工看行情（不用爬虫，防封号）
- **升级时机**：单量 >50单/月、想在手机随手记账时 → 做一个云数据库小应用（手机网页记账 + 自动算利润），那时才用 SQL

## 四、总路线图（90 天）

```
第1周   投资台账+信号卡(1h) │ 自媒体选题库+定位(2h) │ 闲鱼台账模板(0.5h)
第2周   投资每日简报自动化   │ 自媒体第一篇闭环(公众号)
第3周   自媒体第2篇+周报自动化 │ 闲鱼首批闲置上架练手
第4周   投资月度复盘自动化    │ 闲鱼锁定类目正式运营
第2月   自媒体启动视频流      │ 三台各自进入稳定节奏
第3月   视数据量决定：是否给闲鱼/投资上"云数据库+手机随手记"版
```

**搭建优先级建议**：自媒体 > 投资 > 闲鱼。
理由：自媒体是复利型资产（每篇内容都在积累），投资靠纪律不靠工具（策略卡+简报已足够），闲鱼依赖供应链和精力，适合作为现金流补充最后启动。
