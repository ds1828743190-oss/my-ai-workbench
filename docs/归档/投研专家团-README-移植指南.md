## 二、架构解析：这是一个"圆桌多智能体"系统

与单专家不同，这套系统的核心价值是**多视角对抗式研究**，架构为星型（hub-and-spoke）：

```
                 ┌─────────────────────────┐
                 │  主理人 圆汇众（编排者）    │
                 │  拆维度 → 调度 → 汇编收口   │
                 └───────────┬─────────────┘
        ┌─────────┬─────────┼─────────┬─────────┬─────────┐
        ▼         ▼         ▼         ▼         ▼         ▼
    产业策略师  信号派首席  估值分析师  逆向投资人  财报研究员  短线冲浪手
   （并行独立工作：各自取数 → 各自方法论分析 → 回传主理人，成员间互不通信）
```

**三条铁律决定了它的产出质量**（移植时必须保留语义）：
1. **成员独立并行**：6 位同时启动、互相看不到对方结论，防止观点被带偏——分歧是产品的一部分
2. **枢纽中转**：所有信息流经主理人，跨成员整合只发生在汇编层
3. **谁分析谁署名**：主理人只编排不代写专业结论；缺席席位明确标注，不补位

## 三、移植映射表

| 本系统机制 | 作用 | 映射到常见框架 |
|---|---|---|
| 主理人提示词 `stock-partner-lead.md` | 任务拆解、维度映射、汇编规则、铁律约束 | Supervisor / 编排节点 System Prompt |
| 6 份子代理提示词 `agents/*.md` | 各自的人设+方法论+产物规范 | 6 个 Worker Agent 的 System Prompt |
| TeamCreate + Agent spawn | 创建协作空间 + 并行拉起成员 | LangGraph `Send()` 并发 / CrewAI Crew / AutoGen GroupChat / asyncio.gather 多次 LLM 调用 |
| SendMessage 回传 | 成员把完整报告正文交回主理人 | Worker 返回值 / state 聚合（正文即交付物，不落盘） |
| 共享快照注入 | 主理人取一次行情快照写进所有成员任务，防重复取数 | 预取数据放入每个 worker 的输入 payload |
| 执行预算（取数≤4次 / 800-1500字） | 控制成本与跑题 | worker 的 max_tool_calls / max_tokens 约束 |
| 恢复纪律（中断后发一次恢复指令） | 防单个 worker 卡死拖垮全场 | 超时重试 1 次 → 失败则标注缺席，不阻塞 |
| 4 模块报告结构（结论卡→子专家观点→深度思考→后续关注） | 汇编层的固定产出骨架 | 主理人的最终输出模板（照抄即可） |
| md-to-html 渲染管线 | 报告变高保真分享页 | 直接复用：`render.py` 是独立 Python 脚本，零依赖可跑 |
| westock-data / westock-tool skills | 连接器取数规范 | 数据层提示词，配合你的数据源改写 |

**最小可行移植（若不用多智能体框架）**：用 6 次并发 LLM 调用模拟——同一个用户问题 + 各自的 agents/*.md 作为 System Prompt + 同一份行情数据，收集 6 份输出后用主理人提示词（汇编部分）生成圆桌报告。丢掉编排细节也能拿到 80% 的多视角价值。

## 四、数据依赖：腾讯自选股连接器（westock-mcp）

本专家团强依赖 westock-mcp 取实时行情/财务/资金/选股数据（工具规范已含在 `skills/westock-data`、`skills/westock-tool`）。移植到你的工作台：

1. **有凭据路线**：向腾讯自选股开放平台申请接入，或用任何兼容数据源按两个 skill 里的字段语义做适配层
2. **无凭据路线**：AKShare / Tushare /东方财富等开源数据替代，改写两个 skill 中的工具清单即可——6 位成员的方法论提示词不依赖具体数据源
3. **降级纪律（值得保留）**：原设计在连接器不可用时自动降级 WebSearch 取数，并在产出中标注精度受限、数字标注「待核实」——这个诚实降级模式建议照搬

## 六、落地清单（建议顺序）

1. **先单测成员**：拿 6 份 agents/*.md 各自跑一次"分析某只股票"，验证每人输出确实长在各自的独特增量区（产业/信号/估值/逆向/财报/短线），而非同质化
2. **再搭编排**：实现并行调度 + 结果收集 + 主理人汇编，跑通单股深度研究场景（样例 A）
3. **后加渲染**：接 md-to-html 管线（`python3 render.py body.html out.html --title=... --date=...`），产出可分享 HTML
4. **最后接数据源**：从 WebSearch/开源数据起步，有条件再接结构化行情源

> 提示：另一个单专家形态的「研股股」移植包在同工作区 `研股股-专家移植包/` 目录，两者互补——研股股适合"一份深度报告"，专家团适合"多视角圆桌"。 westock 连接器文档在两个包里都有覆盖。
