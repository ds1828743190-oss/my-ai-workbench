## 二、专家包设计要点（对用户原文的落地方式）

- 用户原文（0–7 节：运行定位 / 核心目标 / 八模块库 / 情景路由 / 工作流 / 输出模板 / 交互规则 / 总原则）**作为 SKILL.md 主体原样保留**，仅追加"附录 A：与本仓库资产的衔接"（模块 ↔ 工具路径映射）；
- 八个模块扩展为 `modules/01–08`：每个文件 = 用户列出的检查要点 + 展开方法（清单/阈值区间/模板），非人格化措辞；
- 新增 `modules/09-情景路由示例`：十个典型场景的"判断 → 模块组合 → 输出骨架 → 注意点"；
- 与既有资产打通：量化模块 → `quant-tools/` 三件套；股票模块 → `skills/research-deliverables/`；全部模块 → `skills/data-layer/` 取数纪律；报告 → `skills/md-to-html/`。
