# personal/distillations · 观点蒸馏卡

> 作用：把"我喜欢的博主/大师的一个观点"蒸馏成可复用、可验证、可回写策略的结构化卡片。
> 这是项目演化层（L5）的入口之一——所有外部观点先进这里，**不直接改核心策略**。

## 使用流程

```
读到/听到一个好观点
   │
   ▼
复制 _模板-观点蒸馏卡.md 新建一张卡（文件名：YYYY-MM-DD-博主名-一句话主题.md）
   │
   ▼
填写：原话逐字 → 一句话归纳 → 我的评注与适用边界 → 与现有策略的关系
   │
   ├─ 印证现有规则 → 标注 status: 已共鸣（可作为复盘素材）
   └─ 补充盲区 / 与现有规则冲突 → 标注 status: 已纳入策略候选
                                  并复制一份要点到 ../strategy-candidates/
```

## 规则

- **原话逐字保留**，归纳与评注必须与原文分开（不混写、不改写原意）；
- 与核心策略冲突的观点**不禁写**——它是候选区的原料，但禁止直接触发操作；
- 每月复盘日统一走"候选 → 观察 → 转正/放弃"流程（详见 ../strategy-candidates/README.md）。
