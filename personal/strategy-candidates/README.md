# personal/strategy-candidates · 策略候选区

> 作用：**未转正的我的想法**先在这里"冷藏"——附验证标准，定期复盘，成熟才进核心策略。
> 原则：核心策略（股债利差定投法）固化、不自由发挥；演化走流程、不靠冲动。

## 一张候选卡包含什么

```
- 一句话想法
- 来源：自悟 / 蒸馏卡（链接） / 报告启发
- 与核心策略的关系：补充 / 修正 / 冲突
- 验证标准：看什么数据、观察多久、什么条件下算验证通过
- 状态：观察中 | 已验证待转正 | 已转正 | 放弃（写明原因）
```

## 转正流程（每月最后一个交易日·月度复盘日）

1. **清点**：把「观察中」的卡片过一遍，按验证标准对照真实数据/执行记录；
2. **裁决**：
   - 验证通过 → **转正**：改 `workbenches/investment/strategy/` 对应文档（策略规则类改动需在文档内记一条修订理由），卡状态置「已转正」；
   - 证据不足 → 延长观察并更新标准；
   - 证伪 → 置「放弃」并写明原因（防止同一个错误想法反复回来）；
3. **回执**：把本次裁决写进当月净值月度表的"操作摘要"或复盘记录。

> 冲突处理原则：候选与核心策略冲突时，**默认维持核心策略**；要修改核心，必须候选转正流程完整走完，并在修订记录中留痕。
