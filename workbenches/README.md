# workbenches · 个人工作台（核心层）

> 定位：**跨平台最小可用内核**——任何 AI（Claude / ChatGPT 网页版、手机、WorkBuddy）粘贴即用。
> 这一层刻意保持"轻"：不含人格库、不含技能库，只有"我是谁、按什么规则做事"。

## 各环境用法

| 场景 | 操作 |
|---|---|
| WorkBuddy 新会话 | 把 `prompt.md` 粘进第一句话，接「今日简报」等指令即可；有连接器时自动用全量数据，另有交易日 17:35 简报自动化 |
| Claude / ChatGPT 网页版 | 粘贴后先发「环境自检」，让 AI 报告有没有文件/搜索能力，再下指令 |
| 手机上临时用 | 粘贴提示词 + 手动贴上想让它处理的数据（如台账数字） |
| 有文件系统环境 | 提示词的"环境自适应"段会优先读写台账/协议/信号卡（路径按实际工作目录调整） |

## 与 investing-os 的关系

- 轻环境：只用本层（一段提示词走天下）；
- 重环境（有 Agent 编排能力）：本层作入口与宪法，按需叠加 `../investing-os/` 的人格库/编排模式/技能层/量化工具；
- 任何模式下，涉及动作建议的产出都要回到 `investment/strategy/` 的区间规则复核。

## 安全边界

- `templates/` 内全部为**空白模板**，不含任何真实持仓/交易数据；真实台账只存本地，不入仓库；
- 凭据、token 一律不入库（见仓库根 `.gitignore`）。
