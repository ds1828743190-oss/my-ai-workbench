# 🎬 自媒体工作台 · 总说明

> 定位：**你负责想法和判断，AI 负责一切繁琐的活**。每天投入 ≤15 分钟，周产出 2 篇图文，第 2 月起加视频。

## 目录

| 文件 | 用途 |
|---|---|
| `01-账号定位一页纸.md` | 人设、赛道、平台策略——所有内容创作的总纲，改主意只改这里 |
| `02-选题池.md` | 首批 10 个选题（全部来自你的灵感知识库，素材现成） |
| `03-剪辑效率流.md` | **视频繁琐事务的 AI 代工手册**：压缩/转竖版/字幕/切片一句话搞定 |
| `04-数据追踪表.md` | 每周日填一次，AI 月度汇总 |

## 每周工作流

```
每天（≤15分钟）
  有想法 → 微信发文件传输助手（你原有习惯，不变）
  睡前   → 挑1条发给AI：「整理这条，给出展开角度」

周日（AI 主刀，你只拍板）
  ① 对AI说：「整合本周碎片，更新选题池」
  ② 从选题池挑 2 个 → AI 出草稿 → 你改观点句 → 定稿
  ③ AI 排版 → 推公众号草稿箱（言序连接器）→ 你手机点发布
  ④ 填数据追踪表（1分钟）
```

## 视频线（第 2 月启动）

```
选题 → AI 口播稿+分镜 → 你对着手机念一遍 → 交回 AI：
  转写对轴 → 字幕 → 横转竖/压缩/切片（ffmpeg 一句话）→ 封面图生成 → 三平台分发文案
```

完整指令模板见 `03-剪辑效率流.md`——那是这个工作台自动化能力的核心清单。

## 与 Obsidian 的关系

- 本工作台 = **生产线**（选题→成文→发布→数据）
- 本地 Obsidian 知识库 = **原料库与资产库**（灵感碎片、成稿归档）
- 每篇发布后，让 AI 把定稿同步一份进 Obsidian `02-归档库/09-自媒体AI`，知识资产不散落。
