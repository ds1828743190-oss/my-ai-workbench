# ✂️ 剪辑效率流（AI 代工手册）

> **三分钟原则**：凡是机械、重复、格式类的活（压缩/转竖版/字幕/切片/分发文案）→ 一句话丢给 AI；你只做两件事——**念稿** 和 **决定哪条能用**。
> 视频处理引擎（ffmpeg）已装入 WorkBuddy 隔离目录，无需自己装软件、无需剪映付费功能。

---

| 你要什么 | 直接对我说 |

## B. 剪辑中：机械活一句话代工（ffmpeg）

**不用记命令**——说人话即可，例如「把桌面上的 demo.mp4 压到 50MB 以内」。以下是引擎实际执行的动作，供了解：

### ① 压缩转码（过平台大小/格式限制）
```bash
ffmpeg -i 输入.mp4 -c:v libx264 -crf 28 -preset medium -c:a aac -b:a 128k 输出.mp4
# CRF 每大 6，体积约减半：23≈高清、28≈标准、32≈省流
```

### ② 横版转竖版 9:16（抖音/小红书/视频号）
```bash
# 模糊背景版（主体居中，观感最好）
ffmpeg -i 横版.mp4 -vf "split[a][b];[a]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,boxblur=20[bg];[b]scale=1080:-2[fg];[bg][fg]overlay=(W-w)/2:(H-h)/2" 竖版.mp4
# 居中裁切版（内容满屏）
ffmpeg -i 横版.mp4 -vf "crop=ih*9/16:ih" 竖版_裁切.mp4
```

### ③ 切片 / 去片头片尾
```bash
ffmpeg -ss 00:00:08 -to 00:01:30 -i 输入.mp4 -c copy 精华段.mp4   # 8秒~1分30秒
```

### ④ 抽音频（做播客/配小红书图文）
```bash
ffmpeg -i 视频.mp4 -vn -c:a aac -b:a 192k 音频.m4a
```

### ⑤ 多段合并
```bash
# 先写 list.txt（每行 file '片段1.mp4'），然后：
ffmpeg -f concat -safe 0 -i list.txt -c copy 成片.mp4
```

### ⑥ 倍速 / 音量归一
```bash
ffmpeg -i 输入.mp4 -filter_complex "[0:v]setpts=0.5*PTS[v];[0:a]atempo=2[a]" -map "[v]" -map "[a]" 二倍速.mp4
ffmpeg -i 输入.mp4 -af loudnorm 音量标准.mp4      # 各平台音量统一，免得忽大忽小
```

### ⑦ 字幕烧录进画面
```bash
ffmpeg -i 成片.mp4 -vf "subtitles=字幕.srt:force_style='FontSize=20,Outline=1'" 带字幕.mp4
```

### ⑧ 整个文件夹批量转码（一次性整理素材库）
```bash
for f in 素材/*.mov; do ffmpeg -i "$f" -c:v libx264 -crf 26 "${f%.mov}.mp4"; done
```

## C. 剪辑后：AI 全包

| 事项 | 直接对我说 |
|---|---|
| 三平台分发文案 | 「给这条视频生成公众号/小红书/抖音三版标题+简介+话题标签」 |
| 封面图 | 「生成竖版封面图：主题XX，风格克制有质感」（AI 生图） |
| 数据周报 | 每周日把各平台数据贴给我 → 汇总进数据追踪表 |

## D. 典型一条龙（以后照抄这个流程）

```
1.「写选题07的口播稿+分镜」          → 你拿到稿子
2. 手机念一遍录屏/口拍（10分钟）
3.「把 ~/Movies/07.mp4 转竖版+压到平台限制+字幕烧录」→ AI 一次做完
4.「生成封面+三平台文案」            → 发布
5.「发布数据：公众号X阅读、抖音X播放」 → AI 记入周报
```

## E. 第 2 月可加的自动化（等第一条视频跑通后再建）

- 每周日晚自动化：整合本周灵感 → 出 1 条视频口播稿草稿 → 连同数据周报一起推送。
- 素材库自动整理：指定文件夹新视频自动转码为统一格式。
